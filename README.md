## 📌 Overview

AI Sales Analytics Assistant is an end-to-end Business Intelligence application that combines Machine Learning and Google Gemini AI to help businesses analyze sales performance, forecast future sales, generate executive reports, and interact with sales data using natural language.

---

## ✨ Features

- 📊 Interactive Dashboard
- 🤖 AI Sales Assistant
- 📉 Machine Learning Sales Prediction
- 📈 Executive BI Dashboard
- 📄 AI PDF Report Generation
- 💬 Natural Language Analyst
- 📊 AI Data Visualizer
- 📚 Forecast History Tracking
- 📥 Export Reports
- 🎯 Smart Business Alerts
